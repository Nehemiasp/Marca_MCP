# Fuentes

Archivos woff2 (subconjunto latino) tomados de los paquetes `@fontsource/bricolage-grotesque`, `@fontsource/instrument-sans` y `@fontsource/jetbrains-mono` v5.3.0. Ambas fuentes están bajo licencia SIL Open Font License 1.1 (ver los archivos `LICENCIA-*.txt`).

| Archivo | Uso |
|---|---|
| `bricolage-grotesque-latin-800-normal.woff2` | Títulos, nombre y cifras grandes |
| `instrument-sans-latin-{400,500,600,700}-normal.woff2` | Texto, interfaz y etiquetas |
| `jetbrains-mono-latin-400-normal.woff2` | Solo fragmentos de código en documentación (`tipografia.familia.codigo`) |
